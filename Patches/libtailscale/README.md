# libtailscale patches

Patches apply in filename order to the exact commit in `libtailscale.ref`.
`0001-official-tailscale-version.patch` is generated by `Scripts/upstream.py` and
locks the official release in `Tailscale.version`, its transitive Go dependencies,
and the Go requirement (with the build toolchain pinned in `.go-version`).
`0002-integration-package-name.patch` updates upstream test imports for the
integration package name. The build fails on a patch
conflict; upstream source is never checked into this wrapper repository.

Our Apple bridge is an additive overlay from `Bridge/`. Keep modifications to
existing upstream files as patches here. Update `Tailscale.version` and the
locked dependency patch together when upgrading Tailscale.

The updater regenerates the dependency patch from the selected upstream commit,
with the bridge present during `go mod tidy`. Other patches are rebased using
Git's three-way application and re-emitted against that commit. Conflicting
source changes stop the update without changing checked-in pins or patches.
Keep compatibility/source edits in separate numbered patches, never in the
generated dependency patch. An absorbed patch that no longer applies requires
manual review and removal.
